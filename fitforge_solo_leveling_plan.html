FITFORGE

SYSTEM CONCEPT
FitForge is a Solo Leveling–themed personal fitness web app that treats every workout like a dungeon raid. You gain XP, level up, track your "hunter stats", and get AI-coached by an adaptive system that knows your fatigue, volume, and progress. The dark UI, rank badges, and stat screens are designed to keep you locked in.
001

Core Philosophy

Hunter System
Every user is a Hunter. You gain XP per workout, level up (E→D→C→B→A→S), unlock rank badges and cosmetic themes as you progress.
GAMIFICATION
AI Shadow Coach
Powered by Gemini Pro for plan generation and Groq/LLaMA 3 for real-time chat. The coach analyzes your Fitness, Fatigue, and Form scores — just like the PDF architecture.
AI-POWERED
Readiness Gate
Before each session, the system checks your Fitness score (6-week volume load) vs Fatigue score (7-day RPE+volume). If overloaded, it gates you into a deload.
SUPABASE
002

What Makes It Unique

Unlike generic fitness apps, FitForge is built for resistance training specifically — Push/Pull/Legs, progressive overload, RPE tracking, and hypertrophy-focused metrics. The AI doesn't give generic advice; it reads your actual logged sets and weights from Supabase to personalize everything.
The Solo Leveling aesthetic isn't just cosmetic — it's a motivational system. Seeing your rank go from E → D → C feels real because it's tied to actual workout data: total volume lifted, consistency streak, PRs broken.

RAG Context Pattern

How the Shadow Coach reads your data:

User asks: "Why are my shoulders still sore after 3 days?"

1. Frontend sends query to Supabase Edge Function
2. Edge Function fetches last 14 days of shoulder/push workouts from DB
3. Computes total push volume, sets, average RPE, days since last session
4. Injects all this as structured context into Groq prompt
5. LLaMA 3 reasons over REAL data and returns specific advice

This mirrors the function-calling architecture from the PDF — just adapted to use Supabase instead of Firebase, and Groq instead of Gemini Flash.
